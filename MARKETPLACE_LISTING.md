## 📖 Full Description

### Stop Breaking APIs. Start Shipping Faster.

**Kei** is a real-time API contract validation plugin that catches mismatches between your code and your API specifications before they cause production incidents. Supporting OpenAPI 3.x, Swagger, and GraphQL schemas across TypeScript, JavaScript, Python, Java, and Kotlin — Kei validates your implementation in under 50ms.

#### 🔥 Why Kei?

**Problem:** API contract violations are the #1 cause of integration failures in microservice architectures. Breaking changes slip through code reviews, cause downstream outages, and erode trust between teams. Manual contract validation doesn't scale.

**Solution:** Kei validates your code against your API contracts in real-time as you type. Get instant inline error underlines for mismatched types, missing fields, and breaking changes — with one-click quick-fixes to bring your code back in compliance.

#### ⚡ Key Features

**🔍 Automatic Contract Discovery**
- OpenAPI 3.x and Swagger auto-detection
- GraphQL schema discovery
- Contracts detected automatically on project open

**⚡ Real-Time Validation (<50ms)**
- Inline error underlines for contract violations
- Breaking change detection as you edit
- Support for TypeScript, JavaScript, Python, Java, and Kotlin

**🛠️ Smart Quick-Fixes**
- `Alt+Enter` to fix contract violations
- Auto-add missing fields
- Type mismatch correction
- Contract Explorer tool window for browsing APIs

**📊 Contract Diff Viewer**
- Side-by-side comparison of contract changes
- Breaking vs. non-breaking classification
- Impact analysis ("X files will break")
- Severity levels: Critical, High, Medium, Low

**🖥️ Mock Server Generator**
- Embedded Ktor mock server
- Realistic fake data generation
- Custom mock scenarios
- Request/response logging

**🔗 Version Control Integration**
- Pre-commit hooks with breaking change warnings
- Git history integration
- Branch comparison for contract drift

#### 🚀 Quick Start

1. Install **Kei - API Contract Testing** from the JetBrains Marketplace
2. Open a project containing OpenAPI/Swagger specs or GraphQL schemas — contracts are auto-discovered
3. Open any API implementation file — validation starts immediately with inline error markers
4. Use `Alt+Enter` on any contract violation to apply a quick-fix
5. Browse your API contracts in the **Contract Explorer** tool window
