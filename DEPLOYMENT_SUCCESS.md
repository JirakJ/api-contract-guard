## 📝 Installation Instructions

### Method 1: From Disk
1. Go to IntelliJ IDEA → Settings → Plugins
2. Click ⚙️ → Install Plugin from Disk
3. Select: `build/distributions/kei-plugin-0.1.0-alpha.zip`
4. Restart IDE

### Method 2: From Source
```bash
./gradlew clean buildPlugin
# Plugin will be in: build/distributions/
```
