## 🎓 HOW TO USE KEI

### Quick Start (< 2 minutes)

1. **Open Project with API Contracts**
   ```
   Your project should have:
   - openapi.yaml or swagger.json
   - *.graphql schema files
   - REST endpoints in code
   ```

2. **Kei Auto-Discovers Contracts**
   ```
   Look for notification:
   "Kei: Found 3 API contracts"
   ```

3. **Open Contract Explorer**
   ```
   Right sidebar → Kei Contracts tool window
   Browse your API endpoints
   ```

4. **Start Coding**
   ```typescript
   fetch('/api/users', {
     method: 'POST',
     body: JSON.stringify({
       name: 'John'
       // Kei shows: ❌ Missing required field 'email'
     })
   })
   ```

5. **Fix with Alt+Enter**
   ```
   Press Alt+Enter on the error
   Select "Add missing field 'email'"
   Done! ✅
   ```
